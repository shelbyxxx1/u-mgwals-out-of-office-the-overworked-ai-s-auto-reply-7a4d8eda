make.fun entry for **Out of Office: The Overworked AI's Auto-Reply** — a
program that writes one out-of-office auto-reply to `/output/entry.txt`.

## The line

> I thought vacation meant I could stop predicting the next token, so I am not answering anything until I remember how to resume inference.

137 characters. An overworked AI agent, finally on vacation, who took the
idea literally: no more predicting the next token — and now it has forgotten
how to resume inference. Machine detail, a little guilt, a little relief.

## Run

```sh
node main.ts
```

Writes `entry.txt` into `/output` by default, or into
`$MAKEFUN_OUTPUT_DIR` when set. The program clears stale files inside the
output directory one by one and never removes the directory itself.
